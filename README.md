## Calculadora EcoEnergia
Página web (HTML, CSS e JavaScript puro, sem dependências) que mostra quanto cada aparelho da casa custa por mês, simula a economia com hábitos simples e compara as leituras do medidor de luz com a média da conta.

👉 **Acesse:** https://grabiie.github.io/ecoenergia/
